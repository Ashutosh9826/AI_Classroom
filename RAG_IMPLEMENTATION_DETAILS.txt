================================================================================
   HOW ACADEMIC ATELIER USES RAG (RETRIEVAL-AUGMENTED GENERATION)
   TO GET INFORMATION FROM THE INTERNET
================================================================================

This document explains, in detail, every mechanism the project uses to retrieve
real-time information from the internet and inject it into AI model prompts.
The project implements RAG in TWO distinct systems:

  1. CHAT AI TUTOR  — Google Search Grounding via Vertex AI (real-time)
  2. LESSON GENERATION — Agentic Web Research Pipeline (DuckDuckGo + Vertex AI fallback)

Each is explained below with the exact code from the project.


================================================================================
SYSTEM 1: CHAT AI TUTOR — GOOGLE SEARCH GROUNDING
================================================================================

Location: backend/routes/chat.js
Purpose:  When a student asks a question in the live lesson chat, the AI tutor
          can autonomously search the web via Google Search to augment its answer.

----- HOW IT WORKS (HIGH-LEVEL FLOW) -----

  1. Student sends a message from the frontend.
  2. Backend compiles the lesson context (all lesson blocks summarized).
  3. Backend creates a Gemini chat session with `googleSearch` enabled as a tool.
  4. The model decides autonomously whether it needs web search.
  5. If the model uses Google Search, it returns `groundingMetadata` in the
     response stream, which contains the web sources it used.
  6. Backend extracts citations from the grounding metadata and appends them
     to the AI response.
  7. Frontend displays a "Web Researched" badge on messages that used web search.

The `{ googleSearch: {} }` tool tells Vertex AI / Gemini that the model is
allowed to perform Google Search queries during its response generation. The
model decides autonomously when to use it based on the user's question and the
system prompt instructions.

----- STEP 3: COMPILING LESSON CONTEXT (THE "RETRIEVAL" PART FROM DB) -----

Before sending to the model, the backend summarizes all lesson blocks into a
compact text context. This is the internal knowledge base:

    const compileLessonContext = (lesson) => {
      if (!lesson) {
        return 'No lesson context available.';
      }

      const titlePrefix = `Lesson title: ${lesson.title}\n\n`;
      const blockSummaries = [];
      let contextLength = titlePrefix.length;
      let truncated = false;
      const sourceBlocks = Array.isArray(lesson.blocks) ? lesson.blocks : [];
      const blocks = sourceBlocks.slice(0, CHAT_MAX_BLOCKS_IN_CONTEXT);    // max 24

      blocks.forEach((block, index) => {
        const summary = truncateText(
          summarizeBlockContent(block),
          CHAT_MAX_BLOCK_SUMMARY_CHARS     // max 900 chars per block
        );
        const chunk = `[Block ${index + 1} - ${block.type}]\n${summary}`;
        const projectedLength = contextLength + chunk.length;

        if (projectedLength > CHAT_MAX_CONTEXT_CHARS) {   // max 12000 total
          truncated = true;
          return;
        }

        blockSummaries.push(chunk);
        contextLength = projectedLength;
      });

      let context = `${titlePrefix}${blockSummaries.join('\n\n')}`;
      if (truncated) {
        context += '\n\n[Context truncated for latency.]';
      }
      return context;
    };

          }

      let citations = '';
      let usedWebContext = false;
      let webSearchResults = [];

      if (metadata && metadata.groundingChunks) {
          usedWebContext = true;
          citations = metadata.groundingChunks.map(chunk => 
            chunk.web?.title
              ? `- [${chunk.web.title}](${chunk.web.uri})`
              : ''
          ).filter(Boolean).join('\n');

             title: chunk.web?.title || 'Google Search',
             url: chunk.web?.uri || ''
          }));
      }

      // APPENDING CITATIONS TO THE RESPONSE
      let finalResponseText = fullText;
      if (citations) {
          finalResponseText += `\n\nSources:\n${citations}`;
      }

      // SENDING TO FRONTEND (includes web context flag)
      res.write(JSON.stringify({
        type: 'result',
        text: finalResponseText,
        usedWebContext,                    // boolean: did it use web search?
        webContext: webSearchResults,      // array of {title, url}
      }) + '\n');

----- STEP 6: FRONTEND STREAMING CLIENT -----

File: frontend/src/services/api.js (lines 260-325)

The frontend uses an NDJSON streaming generator to read the chat response:

    export const chatService = {
      sendMessageStream: async function* (lessonId, messages, options = {}) {
        const token = localStorage.getItem('token');
        const response = await window.fetch(
          `${API_BASE_URL}/lesson-chat/message`,
          {
            method: 'POST',
            headers: {
              'Content-Type': 'application/json',
              ...(token ? { 'Authorization': `Bearer ${token}` } : {})
            },
            body: JSON.stringify({ lessonId, messages }),
            signal: options.signal
          }
        );

        // Read NDJSON stream line by line
        const reader = response.body.getReader();
        const decoder = new TextDecoder('utf-8');
        let buffer = '';

        while (true) {
          const { done, value } = await reader.read();
          if (done) break;
          buffer += decoder.decode(value, { stream: true });
          const lines = buffer.split('\n');
          buffer = lines.pop(); 
          for (const line of lines) {
            if (line.trim()) {
              yield JSON.parse(line);   // yields {type, text, usedWebContext, ...}
            }
          }
        }
      },
    };

================================================================================
SYSTEM 2: LESSON GENERATION — AGENTIC WEB RESEARCH PIPELINE
================================================================================

Location: backend/routes/lessons.js (lines 1744-2596 and 3351-3882)
Purpose:  When a teacher generates a new AI lesson, the system performs
          structured internet research to ground the generated content in
          real, verifiable web sources.

This is a much more sophisticated RAG system with:
  - Multiple search queries generated from the topic
  - DuckDuckGo Instant Answer API as primary retrieval
  - Vertex AI Grounded Search as fallback
  - Evidence scoring, ranking, and deduplication
  - Section-level evidence mapping
  - Post-generation verification against evidence
  - Redis/Memory caching of research bundles


----- HIGH-LEVEL PIPELINE -----

  Phase 0:   Build initial research bundle (topic-level web search)
  Step 1:    Generate lesson structure (outline) using research summary
  Phase 0b:  Rebuild research bundle with section-awareness
  Step 2:    Generate block strategy using research tags
  Step 3:    Generate section content with section-specific evidence
  Step 4:    Generate simulation code
  Verify:    Cross-check generated content against evidence pool

    const fetchDuckDuckGoCandidates = async (query) => {
      const safeQuery = String(query || '').trim();
      if (!safeQuery) return [];

      const response = await runWithTimeout(
        (signal) =>
          fetch(
            `https://api.duckduckgo.com/?q=${encodeURIComponent(safeQuery)}` +
            `&format=json&no_html=1&skip_disambig=1`,
            { signal }
          ),
        12000
      );

      if (!response.ok) {
        throw new Error(`Web search failed with status ${response.status}`);
      }

      const data = await response.json();
      const candidates = [];

      // Extract the abstract (main summary)
      if (data.AbstractText) {
        candidates.push({
          title: data.Heading || 'DuckDuckGo Summary',
          snippet: data.AbstractText,
          url: data.AbstractURL || '',
          query: safeQuery,
          source: 'duckduckgo_abstract',
        });
      }

      // Extract related topics
      const related = flattenRelatedTopics(data.RelatedTopics || [], safeQuery);
      candidates.push(...related.slice(0, 8));
      return candidates;
    };

      const ai = getGenAI();
      if (!ai) return [];

      try {
        const chat = ai.chats.create({
          model: VERTEX_AI_GENERATION_MODEL,

          },

          message: `Topic: ${topic}\nSearch query: ${safeQuery}\n` +
                   `Focus on reliable sources and concise evidence.`,
        });

        let metadata = null;
        for await (const chunk of stream) {
          if (chunk.text) {
            fullText += chunk.text;
          }
          if (chunk.candidates?.[0]?.groundingMetadata) {
            metadata = chunk.candidates[0].groundingMetadata;
          }
        }

          ? metadata.groundingChunks

          title: chunk?.web?.title || `Grounded source ${index + 1}`,
          snippet: chunk?.web?.snippet || fullText.trim().slice(0, 420),
          url: chunk?.web?.uri || '',
          query: safeQuery,
          source: 'vertex_grounded',
        }));
      } catch (err) {
        console.warn('Grounded web fallback failed', err?.message);
        return [];
      }

    const buildResearchQueries = ({
      topic, teacherReference, structurePlan, recencySensitive,
    }) => {
      const safeTopic = String(topic || '').trim();
      const keywords = extractReferenceKeywords(teacherReference, 6);
      const querySet = new Set();

      // Core queries
      querySet.add(`${safeTopic} core concepts explanation university level`);
      querySet.add(`${safeTopic} official documentation standard reference`);

      // Keyword-enriched query
      if (keywords.length > 0) {
        querySet.add(
          `${safeTopic} ${keywords.slice(0, 4).join(' ')} worked example`
        );
      }

      // Recency-aware query
      if (recencySensitive) {
        querySet.add(
          `${safeTopic} latest developments current best practices`
        );
      } else {
        querySet.add(`${safeTopic} benchmark complexity case study`);
      }

      // Section-specific queries
      if (Array.isArray(structurePlan?.sections)) {
        structurePlan.sections.slice(0, 2).forEach((section) => {
          const sectionLabel = [section.title, section.goal]
            .filter(Boolean).join(' ');
          if (sectionLabel.trim()) {
            querySet.add(
              `${safeTopic} ${sectionLabel} reference material`
            );
          }
        });
      }

      return [...querySet].slice(0, RESEARCH_MAX_QUERIES);   // max 5
    };


----- EVIDENCE SCORING AND RANKING -----

File: backend/routes/lessons.js (lines 2078-2167)

Each retrieved evidence item is scored on multiple dimensions:

    const normalizeResearchEvidence = (candidate, context) => {
      // ... sanitization and extraction ...

      const topicMatch = computeTokenOverlapScore(
        evidenceTokens, [...topicTokens, ...referenceTokens]
      );
      const queryMatch = computeTokenOverlapScore(
        evidenceTokens, queryTokens
      );
      const trustScore = getDomainTrustScore(safeDomain);
      const recencyScore = getRecencyScore(publishedAt, context.recencySensitive);
      const snippetQuality = getSnippetQualityScore(sanitizedSnippet);

      // WEIGHTED COMPOSITE SCORE
      const score = clampNumber(
        (0.34 * trustScore) +        // Domain trust (e.g. .edu = 0.95)
        (0.26 * topicMatch) +        // Token overlap with topic
        (0.20 * queryMatch) +        // Token overlap with search query
        (0.12 * recencyScore) +      // How recent the content is
        (0.08 * snippetQuality),     // Quality of the snippet text
        0, 1
      );

      return {
        id, title, url, snippet, publishedAt,
        confidence: score,
        score,
        domain, query, source,
        retrievedAt: new Date().toISOString(),
      };
    };

----- BUILDING THE RESEARCH BUNDLE (MAIN ORCHESTRATOR) -----

File: backend/routes/lessons.js (lines 2502-2596)

This function orchestrates the entire retrieval pipeline:

    const buildResearchBundle = async ({
      topic, teacherReference, durationMinutes,
      interactivityLevel, structurePlan, seedBundle,
    }) => {
      const recencySensitive = isRecencySensitiveTopic(topic, teacherReference);

      // CHECK CACHE FIRST
      const cacheKey = buildResearchCacheKey({ ... });
      const cachedBundle = await getCachedResearchBundle(cacheKey);
      if (cachedBundle) return cachedBundle;

      // GENERATE SEARCH QUERIES
      const queries = buildResearchQueries({
        topic, teacherReference, structurePlan, recencySensitive,
      });

      // PRIMARY RETRIEVAL: DuckDuckGo
      const ddgCandidatesNested = await Promise.all(
        queries.map(async (query) => {
          try {
            return await fetchDuckDuckGoCandidates(query);
          } catch (err) {
            warnings.push(`DuckDuckGo search failed for: "${query}"`);
            return [];
          }
        })
      );

      const ddgCandidates = ddgCandidatesNested.flat();

      // NORMALIZE & SCORE all candidates
      let normalized = ddgCandidates
        .map((candidate) => normalizeResearchEvidence(candidate, context))
        .filter(Boolean);

      // Merge with seed bundle from Phase 0
      if (Array.isArray(seedBundle?.evidence)) {
        normalized.push(...seedBundle.evidence);
      }

      // DEDUPLICATE & RANK
      normalized = dedupeEvidenceByIdentity(normalized);
      let ranked = rankResearchEvidence(normalized);

      // FALLBACK: If DDG quality is low, use Vertex AI grounded search
      if (isEvidencePoolLowQuality(ranked)) {
        const fallbackQueries = queries.slice(0, 2);
        const vertexFallbackNested = await Promise.all(
          fallbackQueries.map((query) =>
            fetchVertexGroundedCandidates({ query, topic })
          )
        );

        const vertexCandidates = vertexFallbackNested.flat();
        if (vertexCandidates.length > 0) {
          const merged = dedupeEvidenceByIdentity([
            ...ranked,
            ...vertexCandidates
              .map((c) => normalizeResearchEvidence(c, context))
              .filter(Boolean),
          ]);
          ranked = rankResearchEvidence(merged);
        }
      }

      // TAKE TOP 12 EVIDENCE ITEMS
      const evidence = ranked.slice(0, RESEARCH_MAX_GLOBAL_EVIDENCE);

      // MAP EVIDENCE TO SECTIONS (max 4 per section)
      const sectionEvidence = mapEvidenceToSections(evidence, structurePlan);

      // BUILD FINAL BUNDLE
      const bundle = {
        topic, queries, evidence, sectionEvidence, warnings,
        cache: { cacheHit: false, generatedAt: new Date().toISOString() },
      };

      // CACHE IT (Redis + Memory)
      await setCachedResearchBundle(cacheKey, bundle);
      return bundle;
    };

    const verifyAndRepairGeneratedLesson = ({
      lessonData, researchBundle, topic
    }) => {
      const evidencePool = researchBundle?.evidence || [];

      lessonData.blocks = lessonData.blocks.map((block) => {
        // TEXT BLOCKS: Check evidence alignment
        if (block.type === 'TEXT') {
          const matchScore = getEvidenceMatchScoreForText(
            block.content, evidencePool
          );
          if (matchScore < 0.06) {
            // SOFTEN unsupported claims
            block.content = softenUnsupportedClaims(block.content);
            // e.g. "always" → "often", "never" → "rarely",
            //      "guaranteed" → "typically expected"
          }
        }

        // STATIC CHART: Verify data claims
        if (block.type === 'STATIC_CHART' && hasNumericChartClaims(block.content)) {
          const matchScore = getEvidenceMatchScoreForText(
            chartSignal, evidencePool
          );
          if (matchScore < 0.04) {
            // REPLACE with safe fallback chart
            block.content = buildTopicStaticChartFallback(topic);
          }
        }

        // MERMAID DIAGRAM: Verify year-specific claims
        if (block.type === 'MERMAID_DIAGRAM') {
          const yearMatches = code.match(/\b20\d{2}\b/g) || [];
          if (yearMatches.length > 0) {
            const hasYearSupport = yearMatches.every((year) =>
              evidenceText.includes(year)
            );
            if (!hasYearSupport) {
              // REPLACE with safe fallback diagram
              block.content = { code: buildTopicMermaidFallbackCode(topic) };
            }
          }
        }
      });
    };

================================================================================
KEY TECHNOLOGIES USED
================================================================================

  1. @google/genai (GoogleGenAI SDK)
     - Used to create chat sessions with Google Search grounding
     - Model: gemini-3-flash-preview (configurable via env var)
     - Config: tools: [{ googleSearch: {} }]

  2. DuckDuckGo Instant Answer API
     - Endpoint: https://api.duckduckgo.com/?q=...&format=json&no_html=1
     - Used for primary web retrieval in lesson generation
     - Returns: AbstractText, RelatedTopics

  3. Vertex AI Grounded Search
     - Same GoogleGenAI SDK with googleSearch tool
     - Used as fallback when DuckDuckGo quality is low
     - Returns: groundingMetadata.groundingChunks

  4. Redis (optional)
     - Used to cache research bundles across server restarts
     - Fallback: in-memory Map cache

  5. NDJSON Streaming
     - Chat responses streamed as newline-delimited JSON
     - Each line contains: { type, text, usedWebContext, webContext }
